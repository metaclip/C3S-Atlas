# METACLIP provenance for the C3S Atlas

METACLIP is used to define the provenance model of the Copernicus C3S Atlas (http://atlas.climate.copernicus.eu; see [ECMWF Newsletter, 181](https://www.ecmwf.int/en/newsletter/181/earth-system-science/copernicus-interactive-climate-atlas-tool-explore-regional) for an overview) based on the core [METACLIP semantic ontologies](https://github.com/metaclip/ontologies) through the vocabularies `c3s_terms` (observational and renalyses datasets), provided in this repository, and the `C3S-CMIP6-Single_levels` and `C3S-CORDEX-CMIP5-Single_levels` vocabularies for projections, provided in two separate repositories since they are aligned with CMIP and CORDEX initiatives. 

The `c3s_terms` vocabulary defines a heterogeneous set of entities used in the C3S Atlas, including datasets, modelling centres, data providers, climate indices, and other domain‑specific resources. These entities are described as instances of the classes defined in the METACLIP core [`datasource`](https://metaclip.org/datasource/datasource.owl) ontology. The vocabulary `c3s_terms` extends this core model to provide a consistent semantic framework for describing C3S Atlas‑specific concepts and resources.

The [C3S-CMIP6-Single_levels](https://github.com/metaclip/C3S-CMIP6-Single_levels) repository implements a provenance description of the catalogue "C3S CMIP6 Projections Dataset for the single-level variables" of the Copernicus Climate Data Store (CDS). The provenance description strictly adheres to CMIP6 controlled vocabularies and incorporates a semantic layer, enhancing the interpretability of provenance information through the CMIP6 vocabularies of METACLIP. 

The [C3S-CORDEX-CMIP5-Single_levels](https://github.com/metaclip/C3S-CORDEX-CMIP5-Single_levels) vocabulary implements a provenance description for the catalogue "CORDEX regional climate model (RCM) data on single levels" of the Copernicus CDS. The provenance builds on the metadata for models and model components available for the [CORDEX-CMIP5](https://github.com/metaclip/CORDEX-CMIP5) dataset in the paper "The Worldwide C3S CORDEX Grand Ensemble: A Major Contribution to Assess Regional Climate Change in the IPCC AR6 Atlas" ([Díez et al. 2022](https://doi.org/10.1175/BAMS-D-22-0111.1)).
